React Navbar (useRef Practice)

A simple responsive React Navbar built to practice using useRef.
It dynamically controls the height of the links container using DOM measurements instead of fixed CSS.

🧠 What I Practiced

Using useRef to access and measure DOM elements

Expanding/collapsing navbar links smoothly

Managing state with useState

Using icons from react-icons

⚙️ Technologies

React

Vite

React Icons

CSS

💡 Purpose

This project helped me understand how useRef works for DOM manipulation in React and how to build a clean, responsive navbar.
